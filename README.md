# ShipRoyale

A personal Java desktop Battleship-style game originally developed as a college project. The source includes a 10-by-10 game board, player screens, and NetBeans GUI forms.

## Stack and current scope

Java 8, Swing/AWT, NetBeans Ant project (build.xml). The original README refers to JavaFX, but the inspected game source uses Swing.

## Running locally

```bash
ant clean jar
# Alternatively open the project in NetBeans and build/run there.
```

These are development commands, not a guarantee that the project runs without environment configuration.

## Current limitations

Contains image assets whose licensing has not been verified; review and replace any third-party images before public redistribution or licensing. The game uses Swing, not JavaFX.
